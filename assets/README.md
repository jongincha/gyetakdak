# 로컬 이미지·영상 폴더 안내

이 사이트의 이미지/영상은 더 이상 Cloudinary 외부 URL을 쓰지 않고, 이 `assets/` 폴더
안의 로컬 파일을 직접 불러옵니다 (`index.html`의 `src="./assets/..."`).

## 폴더 구조

```
assets/
  images/
    logo.png            헤더 로고
    factory-01.jpg ~ factory-08.jpg   자체 공장 갤러리 (8장)
    menu-01.jpg ~ menu-14.png          대표/사이드 메뉴 사진 (14장, menu-10만 .png)
    review-01.jpg ~ review-15.jpg      SNS 고객 후기 사진 (15장)
    store-01.jpg ~ store-07.jpg        매장 소개/인테리어 갤러리 (7장)
  videos/
    hero-bg.mp4          (선택) 히어로 배경 영상 mp4 롤백용 — 현재는 유튜브 쇼츠 임베드가 기본
    intro-bg.mp4         (선택) 인트로 배경 영상 mp4 롤백용 — 현재는 유튜브 임베드가 기본
```

파일명은 **위 표와 정확히 똑같이** (대소문자·확장자 포함) 맞춰야 코드가 바로 인식합니다.
'다운로드 > 계탉닭' 폴더에 있는 원본 파일을 이 이름으로 복사/변경해서 넣어주세요.

현재 히어로/인트로 영상은 유튜브 임베드가 기본으로 켜져 있어서 이 mp4 파일이 없어도
사이트는 정상 작동합니다. 유튜브 대신 자체 mp4로 되돌리고 싶을 때만 필요하며,
`index.html`의 해당 섹션 주석에 교체 방법이 적혀 있습니다.

## 파일을 넣는 방법

1. 이 저장소(GitHub)의 `claude/ui-ux-pro-max-skill-rules-c66t0o` 브랜치에서
   `assets/images/`, `assets/videos/` 경로에 맞춰 파일을 업로드합니다
   (GitHub 웹 화면의 "Add file → Upload files" 사용 가능).
2. 또는 이 대화창에 이미지 파일을 직접 첨부해서 보내주시면, 받아서 같은 경로에
   저장하고 커밋까지 진행해 드립니다. (용량이 큰 영상 파일은 채팅 첨부보다
   GitHub 업로드가 더 안정적입니다.)

## 업로드 확인 결과 (참고용 기록)

- GitHub 웹 업로드로 파일이 `assets/` 바로 아래(폴더 구분 없이)에 올라와서
  `assets/images/`로 옮겨 코드 경로와 맞췄습니다.
- `logo.png.png`로 두 번 겹친 확장자는 `logo.png`로 정정했습니다.
- `factory-08.jpg`가 새로 추가되어 있어서 갤러리 슬라이드/썸네일을 7장 → 8장으로
  늘려 반영했습니다.
- `또띠아 계탉닭.html`이라는 파일이 같이 올라왔는데, 열어보니 현재 이 사이트
  (gyetakdak.com)를 브라우저에서 "다른 이름으로 저장"한 페이지 스냅샷이었습니다.
  이미지가 아니라서 코드에서 쓰지 않고 그대로 뒀습니다 — 다운로드 폴더에 섞여있던
  파일이 같이 올라온 것 같으니, 필요 없으면 GitHub에서 직접 지워주세요.
